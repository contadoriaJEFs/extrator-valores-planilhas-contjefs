▼ℹ️ Instruções e Compatibilidade

Formatos de Competência Disponíveis:

  • Data Completa Exporta como 01/MM/AAAA. Recomendado para fórmulas e cálculos de data no Excel.
  • Ano-Mês Formato "AAAA-MM" - Padrão internacional para agrupar.
  • Original Formato "Mmm/AA" - Como aparece no PDF.

Compatibilidade:

Este leitor funciona com PDFs de RMI no formato padrão da Justiça Federal, onde cada linha contém: Competência (Mmm/AA) + Salário-de-Contribuição em colunas. Se o PDF não for reconhecido, use o diagnóstico técnico para ver como o texto está sendo extraído.

// Exemplo de uso no Excel: =DIAS360(A2;A3) // Calcula dias entre competências =DATADIF(A2;HOJE();"Y") // Calcula anos de contribuição =MÊS(A2) // Extrai o mês da competência =SOMASE(B:B;">1000") // Soma salários acima de 1000 =MÉDIA(B2:B100) // Média dos salários
